# Spanish for the example sentence rewritten into each form. Format and rules:
# scripts/build_translations.js. Conventions used throughout:
#   pas  に + person → that person is the agent ("El profesor me saluda");
#        otherwise impersonal or the affected "me" ("Me suben los precios").
#   cau  "Le hago / le dejo + infinitivo", or "Hago que + subjuntivo" when
#        the に phrase is the person made to act.
#   cp   "Me obligan a …" (or "X me obliga a …" when に marks a person).
#   tai  "Quiero …". Inanimate subjects are translated literally.
